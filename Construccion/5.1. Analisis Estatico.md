# Analisis Estatico

Se realizó un trabajo enfocado en mejorar la calidad y robustez del código del proyecto `RazonamientoCuantitativoBackend` a través de la implementación de pruebas unitarias.

## Problemas Conocidos

* De acuerdo con el reporte dado por **ESLint**, muchos de los archivos JSX contienen errores tipo `react/react-in-jsx-scope`. Estos existen únicamente cuando las funciones de la librería `react` son ejecutadas globalmente, pero a partir de las nuevas versiones de React (v17 en adelante) permiten esta función, se ignoran estas advertencias.

* También se puede notar que el código del motor de juegos **Godot** presenta advertencias. Esto también se puede descartar, por lo que esto proviene de la compilación web en Godot.

# Pruebas Unitarias

Se realizaron pruebas unitarias a los script encargados de la visualización del juego hecho en **Godot**; usando **Jest**, y se verificó que existiese cobertura del **100%**. En cuanto al desarrollo en el motor de juegos **Godot**, se cuenta con una interfaz intuitiva, lo cual permite realizar pruebas de funcionalidad antes o durante la ejecución. Se calculó una cobertura superior al **95%**.
