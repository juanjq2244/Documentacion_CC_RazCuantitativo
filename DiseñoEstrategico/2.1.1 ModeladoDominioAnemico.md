# 2.1.1. Modelo de Dominio Anemico

![Dominio_Anemico](/Imagenes/ModeladoDominio_RazCuan.png)

## Objetos de Dominio

- **Estimulo**: Objeto de dominio correspondiente a cada subnivel de cada tarea.
- **Respuesta Estimulo**: Objeto de dominio correspondiente a cada respuesta dada por el estudiante por estimulo.
- **Opcion de Respuesta**: Objeto de dominio correspondiente a las opciones de respuesta por estimulo.
- **Nivel**: Objeto de dominio correspondiente al grado de dificultad en cada tarea.
- **Tutorial Nivel**: Objeto de dominio correspondiente a la serie de instrucciones por cada nivel.
- **Tarea**: Objeto de dominio correspondiente a las actividades con cierta tematica a desarrollar dentro de la variable.
- **Tutorial Tarea**: Objeto de dominio correspondiente a la serie de instrucciones por cada tarea.
