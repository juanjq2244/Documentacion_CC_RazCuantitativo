# Calidad de Código

Se realizó un trabajo enfocado en mejorar la calidad y robustez del código del proyecto `RazonamientoCuantitativoBackend` a través de la implementación de pruebas unitarias.

## Problemas Conocidos

* A partir del reporte dado por ESLint, muchos de los archivos JSX contienen errores tipo "react/react-in-jsx-scope", que existe únicamente cuando las funciones de la librería "react" son ejecutadas globalmente, pero como las nuevas versiones de React (a partir de v17) permiten esta función, se ignoran estas advertencias.

* También se puede ver que el código relacionado con el motor de juegos "Godot" tiene advertencias, esto también se puede descartar, por lo que esto proviene de la manera como Godot compila el juego a un proyecto web.
