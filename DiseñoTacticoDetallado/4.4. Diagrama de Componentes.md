## Componentes Internos de la Aplicación

### API
La puerta de entrada a la aplicación. Esta capa recibe las peticiones HTTP, utiliza los controladores para procesarlas y envía las respuestas al cliente.

### Setup
Lo que organiza todo antes de iniciar la aplicacion, es la única responsable de comunicarse con la base de datos PostgreSQL para crear, leer o actualizar registros.

### Frontend
Es todo lo visual de la aplicación, osea, lo que un usuario ve y interactua con.

---

## Plataforma y Librerías Externas

- **Node.js v19:** El entorno de ejecución. Es la plataforma que ejecuta todo el código JavaScript de la aplicación en el lado del servidor.

- **Vite:** La herramienta de desarrollo y construcción para proyectos web modernos. Es un transpilador de alta velocidad que convierte el código JavaScript moderno a una versión que el entorno Node.js puede entender y ejecutar eficientemente.

- **express:** El framework web minimalista sobre el que se construye la capa API, proveyendo las herramientas para gestionar rutas y peticiones.

- **pg:** El cliente de base de datos que permite a la capa Repository conectarse e interactuar con PostgreSQL.

- **Godot:** El motor de juegos multiplataforma en donde corre el juego central.
