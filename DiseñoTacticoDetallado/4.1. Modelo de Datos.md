# **Explicación de Entidades del Modelo Entidad-Relación (MER) - Sistema de Tareas Cognitivas**

## **Entidades Principales (Estructura Jerárquica)**

Estas entidades representan la estructura principal del sistema de tareas cognitivas.

* **`RC.Tarea`**
    * **Propósito:** Almacena las diferentes tareas o juegos cognitivos disponibles en el sistema.
    * **Atributos Clave:** `nombre` (ej. "El Suelo es Lava"), `indice` (orden de presentación, 1-4).
    * **Relaciones:** Es la raíz jerárquica, contiene múltiples `RC.Nivel` y `RC.TutorialTarea`.

* **`RC.Nivel`**
    * **Propósito:** Representa los diferentes niveles de dificultad dentro de cada tarea.
    * **Atributos Clave:** `intensidad` (1-3, donde 3 es el más difícil).
    * **Relaciones:** Pertenece a una `RC.Tarea` y contiene múltiples `RC.Estimulo` y `RC.TutorialNivel`.

* **`RC.Estimulo`**
    * **Propósito:** Almacena los estímulos o preguntas individuales dentro de cada nivel.
    * **Atributos Clave:** `indiceEstimulo` (orden dentro del nivel), `pregunta`, `tiempoRestante`, `puntos`.
    * **Relaciones:** Pertenece a un `RC.Nivel` y tiene múltiples `RC.OpcionRespuesta`.

## **Entidades de Contenido y Tutoriales**

Estas entidades gestionan las instrucciones para los usuarios.

* **`RC.TutorialTarea`**
    * **Propósito:** Contiene los mensajes tutoriales específicos para cada tarea.
    * **Atributos Clave:** `mensaje`, `tiempoLimite`, `indiceMensaje` (orden de presentación).
    * **Relaciones:** Pertenece a una `RC.Tarea`.

* **`RC.TutorialNivel`**
    * **Propósito:** Almacena los mensajes tutoriales específicos para cada nivel.
    * **Atributos Clave:** `mensaje`, `tiempoLimite`, `indiceMensaje`.
    * **Relaciones:** Pertenece a un `RC.Nivel`.

## **Entidades del Sistema de Respuestas**

Este es el núcleo del sistema de evaluación, gestiona las preguntas y respuestas.

* **`RC.OpcionRespuesta`**
    * **Propósito:** Almacena las posibles opciones de respuesta para cada estímulo.
    * **Atributos Clave:** `opcion` (texto de la respuesta).
    * **Relaciones:** Pertenece a un `RC.Estimulo` y puede ser marcada como correcta en `RC.RespuestaCorrecta`.

* **`RC.RespuestaCorrecta`**
    * **Propósito:** Define cuál opción de respuesta es la correcta para cada estímulo.
    * **Atributos Clave:** Relación directa con una opción específica.
    * **Relaciones:** Referencia una `RC.OpcionRespuesta` específica.

* **`RC.RespuestaEstudiante`**
    * **Propósito:** Registra las respuestas proporcionadas por los usuarios/estudiantes.
    * **Atributos Clave:** `intentos`, `tiempoRestante`, `puntos` obtenidos, `sesion` (identificador de sesión).
    * **Relaciones:** Almacena la `RC.OpcionRespuesta` seleccionada por el usuario.
