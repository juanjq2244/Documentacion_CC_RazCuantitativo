# **Contratos de API**

### **1. POST /api/query**
**Propósito**: Ejecutar solamente consultas SELECT en la base de datos

**Request Body**:
```json
{
  "query": "SELECT * FROM tabla WHERE condicion"
}
```

**Response Success (200)**:
```json
[
  { "columna1": "valor1", "columna2": "valor2" },
  { "columna1": "valor3", "columna2": "valor4" }
]
```

**Response Error (400)**:
```json
{
  "error": "Only SELECT queries are allowed"
}
```

**Response Error (500)**:
```json
{
  "error": "Database error",
  "details": "Mensaje específico del error"
}
```

---

### **2. POST /api/answers**
**Propósito**: Guardar respuestas de estudiantes

**Request Body**:
```json
{
  "opcion_id": 123,
  "sesion_id": "uuid-sesion",
  "tiempo_restante": 45,
  "puntos": 100
}
```

**Response Success (200)**:
```json
{
  "message": "Combined existing entries" | "New entry created",
  "data": {
    "id": 456,
    "opcion": 123,
    "sesion": "uuid-sesion",
    "tiempoRestante": 45,
    "puntos": 100,
    "intentos": 2
  }
}
```

**Response Error (400)**:
```json
{
  "error": "All fields are required"
}
```

**Response Error (500)**:
```json
{
  "error": "Database error",
  "details": "Mensaje específico del error"
}
```

---

### **3. GET /api/stats/:sesion_id**
**Propósito**: Obtener estadísticas del estudiante por sesión

**URL Params**:
- `sesion_id` (requerido): ID de la sesión

**Response Success (200)**:
```json
{
  "sesion": "uuid-sesion",
  "tiempo_respuesta": 12.5,
  "errores": 3,
  "precision": 75.0,
  "nivel": 2,
  "dificultad": "medio",
  "puntuacion": 450
}
```

**Response Error (400)**:
```json
{
  "error": "sesion_id is required"
}
```

**Response Error (500)**:
```json
{
  "error": "Database error",
  "details": "Mensaje específico del error"
}
```

---

## **Notas:**

1. **Autenticación**: No se requiere autenticación en estos endpoints (basado en el código proporcionado)
2. **CORS**: La aplicación está configurada para aceptar requests de cualquier origen.
3. **Tipos de datos**:
   - `opcion_id`: número entero
   - `sesion_id`: string/UUID
   - `tiempo_restante`: número entero
   - `puntos`: número entero
4. **Validaciones**:
   - Solo se permiten queries SELECT
   - Todos los campos son requeridos en `/api/answers`
   - `sesion_id` es requerido en `/api/stats`
